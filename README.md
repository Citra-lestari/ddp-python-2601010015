## Penjelasan Singkat
1. python latihan1_biodata.py => program ini berfungsi untuk menampilkan biodata dari data yang sudah di simpan sebelumnya menggunakan format f-string

2. python latihan2_persegi_panjang.py => program ini berfungsi untuk membantu pengguna menghitung luas dan keliling dari persegi panjang berdasarkan panjang dan lebar yang di masukkan

3. python latihan3_konversi_suhu.py => program ini berfungsi untuk mengonversi suhu dari Celsius ke Fahrenheit dan Kelvin menggunakan rumus konversi suhu.

4. python latihan4_total_belanja.py => program ini berfungsi untuk enghitung subtotal belanja, PPN sebesar 11%, dan total pembayaran berdasarkan harga dan jumlah barang.
